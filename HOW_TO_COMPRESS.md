# How to Compress Your Video

## 📝 Simple 3-Step Process

### Step 1: Open the Compressor
Double-click the file: **`compress-video-standalone.html`**

It will open in your browser (Chrome, Edge, Firefox, Safari - any will work)

### Step 2: Compress
1. Click "Click to select video" or drag your `earth-zoom.mp4` file
2. Choose quality:
   - **1080p HD** (Recommended) - Best balance
   - **720p** (Mobile) - Smaller file, faster
3. Click **"Compress Video"**
4. Wait 1-3 minutes (depends on video length)

### Step 3: Replace the File
1. Click **"Download Compressed Video"**
2. You'll get: `earth-zoom-compressed.webm`
3. Go to your project folder: `public/`
4. **Backup** your original: rename `earth-zoom.mp4` to `earth-zoom-original.mp4`
5. Rename the downloaded file to: `earth-zoom.mp4`
6. Refresh your website

## ✅ Expected Results

**Before:**
- File size: 20.3 MB
- Laggy scrolling
- Slow loading

**After:**
- File size: 3-6 MB (70-80% smaller!)
- Smooth scrolling
- Fast loading
- Better mobile performance

## 🎯 What Quality Should I Choose?

### 1080p HD (Recommended)
- Best for desktop
- Good quality
- ~3-6 MB file size
- Smooth playback

### 720p Mobile
- Best for mobile-first sites
- Smaller file
- ~1-3 MB file size
- Fastest loading

## 🔧 Troubleshooting

**Q: The compressor isn't working**
- Make sure you're using a modern browser (Chrome, Edge, Firefox)
- Try a different browser
- Check browser console for errors (F12)

**Q: Video quality looks bad**
- Try 1080p instead of 720p
- The original might be lower quality

**Q: File is still too large**
- Try 720p quality
- Or compress again with lower bitrate

**Q: Can I use the original MP4?**
- Yes! Just rename the compressed `.webm` to `.mp4`
- Or update the code to use `.webm`
